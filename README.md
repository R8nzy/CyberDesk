# 🛡️ CyberDesk — Интерактивная платформа киберзащиты

> **CyberDesk** — это интерактивный тренажер цифровой гигиены и ИИ-симулятор атак для людей всех возрастов. Обучение построено по принципам микрообучения (в стиле Duolingo) с адаптивными ИИ-менторами и гибкой системой геймификации.

## 🚨 Проблема и Актуальность

В 2026 году социальная инженерия и киберугрозы вышли на принципиально новый уровень:
* **+45% рост точечного фишинга:** Злоумышленники используют генеративный ИИ для создания индивидуальных атак.
* **$2.1B+ потерь пользователей:** Ежегодный ущерб от мошенничества в социальных сетях и мессенджерах.
* **80% уязвимость старшего поколения:** Пожилые люди наиболее подвержены риску из-за отсутствия понятных и простых инструментов обучения.

---

## 💡 Основная Концепция

**CyberDesk** превращает обучение кибербезопасности из сухой теории в увлекательную ежедневную практику:
1. **Микроуроки (5 минут в день):** Наглядные теоретические модули без сложного сленга.
2. **Практика с ИИ-симулятором:** Диалоги с ИИ, отыгрывающим мошенника, в безопасной среде («безопасная ошибка»).
3. **Персонализация:** Выбор характера ИИ-наставника под предпочтения пользователя.

## ✨ Ключевые Возможности

### 🎮 Геймификация и Экономика
* **Дневной стрик (Streak):** Мотивация заходить каждый день для формирования устойчивых привычек.
* **Кристаллы и XP:** Награда за прохождение уроков и успешное отражение атак «боссов».
* **Внутриигровой магазин:** Покупка «Заморозки стрика», кастомизация аватаров и тем профиля.

### 📱 4 Ключевых Экрана Приложения
1. **Главная (Dashboard):** Прогресс, текущий стрик, XP и быстрый старт очередного урока.
2. **Тренировка (Simulator):** Каталог тем, выбор уровней сложности и чат с ИИ-симулятором.
3. **База знаний (Knowledge Base):** Статьи об угрозах, разборы вирусов и дайджест ИИ-новостей.
4. **Профиль (Profile):** Настройки ИИ-ментора, аватары, магазин и статистика.

## 🤖 ИИ-Менторы

Платформа поддерживает динамическую подстановку характера ментора в системный промпт (Prompt Engineering):
* 🛠️ **Техно-Гений:** Харизматичный тон, инженерные аналогии и лёгкий юмор.
* 🔬 **Ученый-Эрудит:** Строгая логика, факты и академический разбор.
* 🕶️ **Мрачный Аналитик:** Мышление этичного хакера, фокус на анонимности.
* ⚙️ **Кастомный Ментор:** Пользовательская настройка характера и стиля общения.

## 📈 Уровни Обучения

* **Уровень 1 (Базовый):** Надежные пароли, проверка ссылок, защита персональных данных (для детей, новичков и пенсионеров).
* **Уровень 2 (Продвинутый):** Социальная инженерия, распознавание глубокого фишинга, проверка дипфейков и фейковых сайтов.
* **Уровень 3 (Профессиональный):** Разбор вредоносного ПО (трояны, RAT, стилеры, шифровальщики, майнеры).

## 👵 Режим «Забота» (Senior Mode)

Специальный адаптивный режим для старшего поколения:
* Крупный шрифт и контрастные элементы UI.
* Полный отказ от сложного технического сленга.
* **Карточки SOS Security:** Быстрые пошаговые инструкции при звонке «из банка» и кнопка «Спросить близкого».

## 🛠 Технологический Стек

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Frontend** | React / Base44 | Адаптивный SPA-интерфейс, быстрый рендеринг чата |
| **Backend** | Python FastAPI | Микросервисы, сборка динамических промптов |
| **Database** | PostgreSQL | Хранение пользователей, прогресса, стриков и товаров |
| **AI Engine** | OpenAI API / Local LLM | Генерация диалогов атак и ответы ИИ-менторов |
| **Safety** | LLM Guardrails | Системные ограничения на генерацию вредоносных скриптов |
